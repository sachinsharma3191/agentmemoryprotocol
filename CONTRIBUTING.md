# Contributing to AMP

Thanks for your interest in the Agent Memory Protocol. Contributions are very welcome.

AMP is an open specification — the goal is for the community to build implementations, propose extensions, and improve the spec together.

---

## Ways to Contribute

### 📝 Improve the Spec
- Fix typos, clarify wording, improve examples
- Propose new node types, link relations, or operations
- Submit a PR against any file in `spec/`

### 🔧 Build an Implementation
The most valuable contributions right now are **working implementations**. See the open issues tagged [`help wanted`](https://github.com/agentmemoryprotocol/agentmemoryprotocol/issues?q=is%3Aissue+label%3A%22help+wanted%22) for specific targets:

| Implementation | Language | Issue |
|---------------|----------|-------|
| `amp-cli` | TypeScript / Node.js | [#1](https://github.com/agentmemoryprotocol/agentmemoryprotocol/issues/1) |
| `amp-mcp` | TypeScript | [#2](https://github.com/agentmemoryprotocol/agentmemoryprotocol/issues/2) |
| `amp-python` | Python | [#3](https://github.com/agentmemoryprotocol/agentmemoryprotocol/issues/3) |

Want to build something not listed? Open an issue first to discuss.

### 💬 Discuss
- Open an issue for questions, proposals, or feedback
- Comment on existing issues
- Share your use case — real-world examples help shape the spec

### 📣 Spread the Word
- Star the repo
- Tell your agent framework community about AMP
- Write a blog post or share on social

---

## Spec Contribution Guidelines

1. **Open an issue first** for significant changes — discuss before building
2. **One change per PR** — keep PRs focused and easy to review
3. **Update the spec version** in `spec/README.md` if making breaking changes
4. **Add examples** where possible — concrete examples are worth more than abstract descriptions
5. **Be kind** — this is a community spec, not a competition

---

## Code Contribution Guidelines (for implementations)

> Note: reference implementations will live in separate repos under the `agentmemoryprotocol` org.

- Follow the spec strictly — implementations must be spec-compliant
- Include tests
- Document public APIs
- Apache 2.0 license
